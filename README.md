## À propos du projet

Ce portfolio est une single-page application statique inspirée du design **Escape Velocity** de HTML5 UP. Il met en avant une composition éditoriale, des animations fluides et une navigation intuitive.

### Fonctionnalités clés :
- **Design responsive** : Optimisé pour les mobiles, tablettes et ordinateurs.
- **Thème sombre/clair** : Basculez facilement entre les modes de lecture.
- **Filtres et recherche** : Parcourez mes projets et compétences de manière interactive.
- **Formulaire de contact** : Intégration avec Netlify Forms pour recevoir les messages directement par e-mail.

## Technologies utilisées

- **Frontend** : HTML5, CSS3 (Flexbox/Grid), JavaScript (Vanilla).
- **Hébergement & Formulaires** : [Netlify](https://www.netlify.com/).
- **Design** : Inspiré de [HTML5 UP](https://html5up.net/).
